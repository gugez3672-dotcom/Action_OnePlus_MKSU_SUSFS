Daily Notes terminal uses the Termux terminal view and emulator 0.118.0.
The terminal library sources retain their Apache 2.0 notices. The complete
Termux app source and its GPL 3.0 license are provided in the source bundle.

Pinned native packages: Bash 5.3.20 (GPL 3.0), Readline 8.3.6 (GPL 3.0),
libiconv 1.19 (LGPL 2.1 / GPL 3.0), ncurses snapshot 6.5.20250830 (MIT),
libandroid-support 29-1 (Apache 2.0 / MIT), and wcwidth 4 (MIT).
Exact binary package hashes are in packages.json.

Corresponding upstream sources, GNU patches, Termux recipes and build scripts,
and the modified terminal sources are distributed alongside the APK as
DailyNotes_D1.0.88_full_sources.zip. They can also be regenerated with
scripts/package_terminal_sources.py using the pinned source URLs and hashes.
Termux package recipe commit: c03cb76356ece3e350af53ad1285b6198feba3bc
https://github.com/termux/termux-packages/tree/c03cb76356ece3e350af53ad1285b6198feba3bc
https://github.com/termux/termux-app/tree/v0.118.0

Daily Notes independently implements its terminal interaction. MT Manager's
proprietary terminal code and extension package are not included.
